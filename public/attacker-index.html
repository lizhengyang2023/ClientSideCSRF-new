😈 攻击者控制台

通过四个不同的攻击向量，演示如何利用客户端可控的 URL 参数窃取受害者的 Cookie Token。

⚠️ 仅用于安全研究演示，请勿用于非法用途

Case1 · window.open() 劫持

利用第三方登录页面中 window.open() 方法的 URL 参数可控漏洞，通过恶意重定向页面窃取 cookie。

进入攻击页面

Case2 · Location 导航劫持

利用搜索引擎页面中 location.href 或 location.assign() 的 URL 可控漏洞，通过恶意页面窃取 cookie。

进入攻击页面

Case3 · Fetch/Beacon 劫持

利用购物页面中 fetch 或 sendBeacon 的目标 URL 可控漏洞，将 cookie 发送到攻击者服务器。

进入攻击页面

Case4 · WebSocket/SSE 劫持

利用聊天应用中 WebSocket 或 EventSource 的连接 URL 可控漏洞，在连接建立时窃取 cookie。
