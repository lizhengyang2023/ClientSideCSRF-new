🛡️ 客户端请求劫持攻击演示系统

Client-Side Request Forgery (CSRF) Attack Demonstration

⚠️ 警告 本系统仅用于教育目的，展示Web安全漏洞。请勿在生产环境或未经授权的系统上使用这些技术。

📋 实验说明

  1. 受害者服务器：运行在 http://127.0.0.1:3000，模拟正常的Web应用
  2. 攻击者服务器：运行在 http://127.0.0.1:3001，包含恶意攻击页面
  3. 首先在浏览器中打开受害者页面（模拟用户已登录状态）
  4. 然后在同一浏览器中打开攻击者页面（模拟用户访问恶意网站）
  5. 观察攻击者页面如何劫持受害者的请求
🌐 打开受害者页面 ⚔️ 打开攻击者页面

🔍 攻击案例列表

1. 表单自动提交攻击

利用隐藏表单自动提交POST请求，执行转账、修改邮箱等敏感操作。

method: form.submit()

2. 图片标签GET请求劫持

利用img标签的src属性发送GET请求，触发用户操作或泄露信息。

method: <img src>

3. Fetch API请求劫持

使用现代Fetch API发送跨域请求，收集用户数据或执行操作。

method: fetch()

4. sendBeacon API数据收集

利用sendBeacon API在页面关闭时发送数据，常用于用户行为追踪劫持。

method: navigator.sendBeacon()

5. JSONP回调劫持

劫持JSONP回调函数，窃取跨域返回的敏感数据。

method: <script> + callback

6. iframe跨域请求劫持

利用iframe加载受害者页面，配合表单提交进行请求劫持。

method: iframe + form

7. XMLHttpRequest劫持

使用传统XHR对象发送AJAX请求，执行后台操作。

method: XMLHttpRequest

8. Link标签CSS导入劫持

利用link标签导入CSS资源时发送请求，可用于探测和攻击。

method: <link rel="stylesheet">

9. WebSocket连接劫持

建立WebSocket连接发送消息，模拟实时通信场景下的数据劫持。

method: WebSocket

10. EventSource/SSE劫持

利用Server-Sent Events建立连接，在实时数据流场景下进行劫持。

method: EventSource

📝 技术说明

本演示系统展示了10种常见的客户端请求劫持攻击方式。这些攻击利用了浏览器的同源策略限制不足， 当用户访问恶意网站时，在用户不知情的情况下，向受害者服务器发送请求。每种攻击都有其特定的应用场景： sendBeacon常用于页面关闭时的数据收集，JSONP用于跨域数据获取，WebSocket用于实时通信等。 所有攻击都在本地环境（127.0.0.1的不同端口）下进行演示，确保安全可控。
